# Funngro Two-Page Redesign

A deployment-ready static HTML/CSS/JS concept for the Funngro website challenge.

## Pages
- `/index.html` — concept landing page
- `/teen.html` — Teen experience
- `/company.html` — Company experience

## Deploy
Upload the entire folder to GitHub Pages, Netlify, Vercel static hosting, or another static host.

## Before submission
1. Replace `https://YOUR-DOMAIN.example` in canonical tags, `robots.txt`, and `sitemap.xml`.
2. Replace illustrative claims/statistics with current, officially verified Funngro information.
3. Replace the external CTA URLs with the exact official destination you want reviewers to use.
4. Test all links and forms/CTAs.
5. Run Lighthouse and fix accessibility/performance issues.
6. Create your SEO audit PDF.

## Important
This is a redesign concept and is not an official Funngro website.
